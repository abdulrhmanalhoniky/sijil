# sijil
⚖️ نظام سجل إدارة القضايا (Sijil - Case Management System) تطبيق مكتبي مخصص لإدارة ومتابعة القضايا القانونية، مصمم لتسهيل تنظيم بيانات الموكلين والخصوم، مع دعم كامل للغة العربية وتصدير التقارير الرسمية بصيغة PDF.
✨ المميزات الرئيسية
إدارة متكاملة للقضايا: تسجيل وتعديل ومتابعة تفاصيل القضايا (بيانات الموكلين، الخصوم، الهويات، وحالة القضية).

واجهة مستخدم عصرية: مصممة باستخدام مكتبة CustomTkinter مع دعم المحاذاة والاتجاهات للغة العربية (RTL).

دعم التقارير الرسمية (PDF): تصدير تفاصيل أي قضية إلى تقرير PDF منسق بدعم كامل للخطوط العربية والتفاف النصوص.

إدارة المستخدمين وقاعدة البيانات: تخزين آمن للبيانات عبر SQLite مع نظام صلاحيات للمستخدمين.

نسخ احتياطي سريع: أداة مدمجة لعمل نسخة احتياطية لقاعدة البيانات مباشرة من واجهة التحكم.

🛠️ التقنيات المستخدمة
Python

CustomTkinter (واجهة المستخدم)

SQLite (قاعدة البيانات)

ReportLab (توليد ملفات الـ PDF)

Arabic Reshaper & Python-Bidi (لمعالجة وتنسيق النصوص العربية)
